# LAC-2367

The macOS offline runner's hosted-runner preflight now uses the
`Offline runner failed (` diagnostic prefix recognized by the existing
standalone annotation parser. An unset or false `GITHUB_ACTIONS` still exits
with status 1 before firewall setup, and the diagnostic names the disposable
hosted-runner requirement.

The clone-proof tests assert this diagnostic for both rejected environments.
Parametrization remains on the test case rather than its helper.
