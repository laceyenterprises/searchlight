# PR-67: suite-validated documentation and report inputs

The CI scope allowlist excludes architecture Markdown, report paths under a
`code` or `data` directory component, and report files named `reproduce.md` or
`suite.yaml`. These inputs require integrity tests beyond the always-on report
and site publication checks; `docs/ci-cost/SLCI-02.md` names those tests.

Scope regression cases live in the existing `tests/test_ci_runners.py` allowlist
table, so default pytest discovery and the offline runner collect the same cases.
The redundant script-level test module and its temporary Git repositories were
removed. Future suite-only report/doc inputs require checking this allowlist when
their tests are added.
